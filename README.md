# 🎮 About Mine Arena

**Mine Arena** is an interactive browser-based arena game created with **HTML, CSS, and JavaScript**.

The project combines an arena-style gameplay experience with mining-inspired elements, player movement, combat, enemies, health, scoring, and game-state mechanics.

The goal was not simply to create a webpage.

The goal was to **build an actual playable experience using web technologies**.

From the initial concept to gameplay logic, interface design, testing, debugging, and final improvements, this project represents a complete hands-on web development journey.

# ✨ Game Features

## 🕹️ Interactive Gameplay

The game provides an interactive arena environment where the player can control their character and participate in the gameplay.

## ⚔️ Combat & Interaction

Players interact with enemies and game elements while attempting to survive and achieve a higher score.

## ❤️ Health System

The player has a health system that makes gameplay more challenging and introduces a survival element.

## 🏆 Score System

Players can work toward achieving a higher score and improving their performance.

## 💀 Game Over

When the player's game state reaches its end, the game transitions into a game-over state.

## 🔄 Restart

Players can restart the game and attempt another run.

## 🎨 Interactive UI

The interface was designed specifically for the game rather than simply presenting static content.

## ⚡ Browser Based

No complicated installation is required.

Open the game in a modern browser and play.
